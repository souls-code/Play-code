# 📝 Application Todo en JavaScript

Une application todo élégante et moderne avec une interface utilisateur intuitive, construite en JavaScript vanilla.

## ✨ Fonctionnalités

- ✅ Ajouter des tâches
- ✏️ Marquer les tâches comme terminées/actives
- 🗑️ Supprimer des tâches individuelles
- 🔍 Filtrer les tâches (Toutes, Actives, Terminées)
- 🧹 Effacer toutes les tâches terminées
- 💾 Sauvegarde automatique dans le localStorage
- 📱 Design responsive et adaptatif
- 🎨 Interface moderne avec animations fluides

## 🚀 Installation

1. Clonez ce repository ou téléchargez les fichiers
2. Ouvrez le fichier `index.html` dans votre navigateur web

Aucune installation de dépendances n'est requise ! L'application utilise uniquement HTML, CSS et JavaScript vanilla.

## 📖 Utilisation

1. **Ajouter une tâche** : Tapez votre tâche dans le champ de saisie et cliquez sur "Ajouter" ou appuyez sur Entrée
2. **Marquer comme terminée** : Cliquez sur la case à cocher à gauche de la tâche
3. **Supprimer une tâche** : Survolez une tâche et cliquez sur l'icône de corbeille
4. **Filtrer les tâches** : Utilisez les boutons "Toutes", "Actives" ou "Terminées"
5. **Effacer les terminées** : Cliquez sur "Effacer terminées" en bas de l'application

## 🛠️ Technologies utilisées

- **HTML5** - Structure de l'application
- **CSS3** - Styles modernes avec animations et transitions
- **JavaScript (ES6+)** - Logique de l'application
- **LocalStorage API** - Persistance des données

## 🎨 Personnalisation

Vous pouvez facilement personnaliser l'apparence en modifiant les variables CSS dans `style.css` :

```css
:root {
    --primary: #6366f1;
    --primary-dark: #4f46e5;
    --success: #10b981;
    --danger: #ef4444;
    /* ... autres variables */
}
```
